TORUS MAP / SIGNED DEGREE

GAME DESIGN TARGET

Fold map의 signed multiplicity를 조작 가능한 mission으로 옮긴 게임

플레이어는 source torus의 점 x=(u,v)를 조종하고 state torus의 F(x)를 동시에 본다. mission의 수학적 대상은 여러 원상의 local degree가 부호와 함께 합쳐져 만드는 mapping degree다.

MECHANIC SEQUENCE

periodic motion → fold crossing → 1-to-3 provenance → signed cancellation → integer packet charge. map과 Jacobian은 연속 모델에서 직접 계산한다. mission charge는 연속 적분이 아니라 authored coverage packet의 부호 합이다.

03

MATHEMATICAL MODEL

구현된 torus fold map

Convention lock

source와 state는 모두 표준 방향을 가진 2-torus T² = (ℝ/ℤ)²이고 좌표는 (u,v), (u′,v′)이다. 면적형은 ω = du′∧dv′, 전체 면적은 1로 정규화한다.

진폭

A(u) = 1.18 + 0.32 cos(6πu)

fold map

F(u,v) = (u′,v′) = (u, v + A(u) sin(2πv)/(2π)) mod 1

  1. 1
    미분한다.

    ∂v′/∂v = 1 + A(u) cos(2πv)

    첫 좌표는 u′=u이므로 derivative matrix는 아래 삼각형 꼴이다.

  2. 2
    Jacobian의 부호가 orientation이다.

    DF = [ 1   0 ; ∂v′/∂u   1+A(u)cos(2πv) ]

    J(u,v) = det DF = 1 + A(u) cos(2πv)

    J>0인 층은 +, J<0인 층은 −다. 따라서 fold를 넘을 때 “점수 규칙”이 임의로 바뀌는 것이 아니라 map의 국소 방향이 뒤집힌다.

  3. 3
    fold와 cusp를 분리한다.

    fold set: J=0 ⇔ cos(2πv)=−1/A(u),   A(u)≥1

    일반 fold에서는 ∂²v′/∂v² ≠ 0이다. 두 fold branch가 만나는 A(u)=1, v=1/2에서는 2차항도 사라지고 3차항이 남는다.

    v′−½ = −A′(uc)ts + (2/3)π²s³ + higher order,   t=u−uc, s=v−½

    즉 국소적으로 (t,s) ↦ (t, s³−ts)형인 cusp다.

04

PULLBACK INTEGRAL ↔ GAME STATE

Degree 적분과 화면 요소의 대응

Degree integral은 source torus의 모든 미소 면적 du∧dv가 map을 지나며 만드는 signed state-area를 합한다.

계산 목표와 type

deg F = [1 / ∫T²stateω] ∫T²sourceF*ω,   ω = du′∧dv′ ∈ Ω²(T²state)

여기서는 ∫T²stateω = 1로 정규화했다. 따라서 분모는 1이고, 분자의 source 전체 적분값이 곧 degree다.

  1. 1
    state의 면적 단위를 source로 당긴다.

    F*ω = F*(du′∧dv′) = d(u′∘F) ∧ d(v′∘F)

  2. 2
    두 좌표를 미분한다.

    du′ = du

    dv′ = [A′(u)sin(2πv)/(2π)]du + [1+A(u)cos(2πv)]dv

  3. 3
    A′(u) 항의 소거.

    F*ω = du ∧ {[A′(u)sin(2πv)/(2π)]du + [1+A(u)cos(2πv)]dv}

    du∧du = 0이므로 첫 항만이 아니라 첫 항이 정확히 소거된다.

  4. 4
    남은 계수가 게임의 Jacobian이다.

    F*ω = [1+A(u)cos(2πv)]du∧dv = J(u,v)du∧dv

  5. 5
    source square 전체—즉 torus의 한 fundamental domain—를 적분한다.

    ∫₀¹∫₀¹ J(u,v) dv du = ∫₀¹[1 + A(u)∫₀¹cos(2πv)dv]du = 1

PLAYER PATH의 TYPE

플레이어 경로는 γ:S¹→T²source인 1차원 곡선이다. 2-form은 1차원에서 사라지므로 γ*(F*ω)=0이다. 화면의 trail은 source gate 방문 순서를 결정하는 controller 기록이다.

손계산의 대상수학적 의미게임에서 보이는 것구현 수준
x=(u,v) source torus의 한 점 왼쪽 DOMAIN의 조종점과 source 좌표 정확
F(x)=(u′,v′) 그 source가 보내지는 state점 오른쪽 STATE SURFACE의 밝은 mapped image 정확
ω=du′∧dv′ state torus의 oriented unit area 직접 그려진 물체가 없음; state의 미소 면적 cell이라는 해석만 존재 개념만
du∧dv source torus의 미소 면적 cell gate 하나가 아님; 화면에는 실제 cell mesh가 없음 개념만
J(u,v) 미소 면적의 signed 배율 ORIENTATION의 ±가 sign J, STRETCH가 |J| 정확
∫T²source 모든 source cell을 빠짐없이 합함 게임은 전체 mesh를 순회하거나 적분하지 않음 미구현
Craw=∫|J|du dv 중복을 모두 양수로 센 면적 RAW meter는 방문한 packet weight의 합으로 대신함 대수적 proxy
Csigned=∫J du dv orientation을 보존해 더한 면적 SIGNED meter는 방문한 packet의 ± weight 합으로 대신함 대수적 proxy
Csigned/∫ω target 전체 면적으로 나누어 degree를 얻음 CHARGE는 authored quantum=1로 나눔; target 면적에서 계산하지 않음 값만 일치
γ(t) 적분식에는 없는 플레이어 경로 gate 방문 순서를 정하는 controller와 증거 trail 조종만

손계산의 연속량

Craw = ∫T²|J|du dv ≈ 1.065606

Csigned = ∫T²J du dv = 1

동치인 target 쪽 표현은 ∫NF(y)ω와 ∫mF(y)ω다. 여기서 NF는 원상 개수, mF는 원상 부호 합이다.

MISSION 04의 유한 packet

signs = (+, −, +, −, +),   ak=1

RAW = Σak = 5,   SIGNED = Σ sign(J(xk))ak = 1

gate를 먹을 때마다 packet 하나를 더한다. 이것은 cell quadrature가 아니므로 RAW 5와 연속 적분값 1.065606은 같은 단위가 아니다. 보존한 것은 “음의 층이 양의 층을 상쇄한다”는 대수뿐이다.

MISSION 03 · REGULAR-VALUE FORMULA

MISSION 03의 흰 state beacon이 정칙값 y, 세 echo가 x∈F⁻¹(y), 각 echo의 ±가 sign det DFx다. 따라서 (+1)+(−1)+(+1)=+1은 regular-value degree 공식을 실제로 재현한다. 반면 MISSION 04의 RAW/SIGNED meter는 면적 적분의 계산이 아니라 그 상쇄 규칙을 압축한 과제다.

GLOBAL MISSION QUANTITY

Mapping degree

정칙값에서 세기

deg F = Σx∈F⁻¹(y) sign(det DFx)

원상의 개수 |F⁻¹(y)|는 1에서 3으로 바뀐다. 하지만 fold를 통과하며 원상은 +/− 한 쌍으로 생기거나 사라지므로 signed sum은 1로 남는다.

면적형으로 독립 검산

∫T²F*ω = ∫₀¹∫₀¹[1+A(u)cos(2πv)] du dv = 1

cos(2πv)의 한 주기 적분이 0이므로 normalized target area로 나눈 degree는 1이다. 또 Ft(u,v)=(u,v+tA(u)sin(2πv)/(2π))가 identity와 F를 잇는 homotopy이므로 degree 1이라는 별도의 검산도 된다.

raw multiplicity1 ↔ 3 ≠ signed multiplicity1 = degree1

IMPLEMENTATION BOUNDARY

연속 map mechanic과 authored packet charge

연속 map에서 직접 계산되는 값

  • 주기성: source 좌표는 실제로 mod 1로 wrap한다.
  • fold sign: 방향은 sign(det DF)에서 직접 나온다.
  • 1↔3 provenance: 동일 state점의 원상을 수치적으로 역탐색한다.
  • cusp: fold branch가 합쳐지는 실제 cusp 조건을 사용한다.
  • 표현 불변성: camera 회전은 F와 charge 계산에 들어가지 않는다.

mission configuration으로 지정되는 값

  • “area” 단위: 수집한 coverage packet의 authored weight.
  • charge: Qgame = Σk εk ak / q로 정의된 gate packet 합.
  • 닫힌 path: 마지막 mission의 route-completion 조건.
  • 정수 target: mission configuration에 배치된 packet 부호 합.

GAME DESIGN SUMMARY

Quantum Fold는 degree-1 cusp/fold map 위에서 source와 image를 함께 조종하고, local sign, 1-to-3 provenance, signed cancellation을 순서대로 수행하는 arcade game이다. mission score의 계산 수준은 authored coverage packet의 signed sum이다.
